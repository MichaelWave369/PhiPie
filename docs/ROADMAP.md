# PhiPie Roadmap

Each rung should remain small enough to fail clearly.

| Rung | Goal | Exit signal |
| --- | --- | --- |
| **PHIPIE-00** | Platform contract + repo skeleton | docs + structural CI |
| **PHIPIE-01** | ARM64 software CI | PhiOS/PhiShell ARM64-compatible test evidence |
| **PHIPIE-02** | Minimal image builder | reproducible ARM64 image artifact |
| **PHIPIE-03** | Raspberry Pi 5 boot | real-board boot + retained evidence |
| **PHIPIE-04** | PhiOS runtime | PhiOS core services execute on board |
| **PHIPIE-05** | PhiShell desktop | qualified display/input/session path |
| **PHIPIE-06** | Headless node mode | bounded remote status/control |
| **PHIPIE-07** | Mission sandbox | isolated bounded mission execution |
| **PHIPIE-08** | Vessie bridge | governed discovery + mission submission |
| **PHIPIE-09** | First PhiBot | one role completes a mission with receipts |
| **PHIPIE-10** | Think Tank | multiple roles preserve independent evidence |
| **PHIPIE-11** | Reliable updates | atomic/A-B update + rollback evidence |
| **PHIPIE-12** | CM5 appliance | separate Compute Module 5 qualification |
| **PHIPIE-13** | Production security | signed boot/encrypted state/provisioning evaluation |

No later rung is implied by completion of an earlier rung.
